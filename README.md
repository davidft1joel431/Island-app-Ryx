# Ryx Isla

Ryx Isla es una aplicación Android de isla dinámica inspirada en [Smart Island](https://github.com/agupta07505/SmartIsland), de Animesh Gupta. Integra notificaciones, controles multimedia, llamadas, temporizadores, navegación, eventos del sistema, widgets y accesos rápidos en una superposición configurable.

Esta versión conserva el identificador `com.dav.isla` para actualizar la instalación existente de Ryx. El código derivado se distribuye bajo GNU GPL versión 3; consulta [LICENSE](LICENSE), [UPSTREAM.md](UPSTREAM.md) y los avisos de terceros.

## Compilar

Se requiere JDK 17 y Android SDK 36. En Windows: `gradlew.bat assembleDebug`.

## Atribución

El proyecto conserva componentes de Smart Island 7.6.0 y sus avisos de autoría y licencia. Ryx Isla es un proyecto independiente y no es un producto oficial de Xiaomi ni de Animesh Gupta.
