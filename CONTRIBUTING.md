# Contributing to Ryx Isla

Ryx Isla is derived from the Apache-2.0-licensed Hyper Bridge project. Keep the upstream copyright and license notices in place when modifying inherited files, and include attribution for newly imported upstream changes.

Build with JDK 21 and Android SDK 36:

```powershell
.\gradlew.bat assembleDebug
```

Use focused pull requests, describe behavior changes, and include a screenshot for interface updates.
