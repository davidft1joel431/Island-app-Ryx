# Cómo colaborar con Ryx Isla

Ryx Isla deriva de Hyper Bridge, distribuido bajo la licencia Apache 2.0. Conserva los avisos de autoría y licencia del proyecto de origen y añade atribución para cualquier cambio importado.

## Estilo del proyecto

- Mantén la interfaz, los textos y la documentación en español castellano.
- En cada actualización, conserva un README visual con el logotipo, imágenes explicativas y emojis que ayuden a entender las funciones.
- Usa capturas reales cuando documentes cambios de interfaz; no presentes diagramas como si fueran capturas de la aplicación.
- Describe los cambios de comportamiento y actualiza las imágenes o explicaciones del README cuando sea necesario.

## Compilación

Se necesita JDK 21 y Android SDK 36:

```powershell
.\gradlew.bat assembleDebug
```
